세션 로그 백업

코코포리아 룸 채팅 ‘메인’ 탭을 그대로 옮겨, 읽기 좋은 반응형 페이지로 저장합니다. 아바타·이름·색상을 살리고, GM은 내레이션으로 흘려 씁니다. 코코포리아 채팅은 가상 스크롤이라, 아래 ‘룸 로그 수집’으로 전체 로그를 먼저 모읍니다.

표시 설정

읽는 방식만 바꿉니다. 아래에서 고친 뒤 ‘변환 · 다시 적용’을 누르면 세션에 곧바로 반영됩니다.

1 로그 수집 · 클릭 한 번

‘룸 로그 수집’ 북마클릿

북마크바에 한 번만 등록해 두면, 다음부터는 룸에서 클릭 한 번으로 전체 로그가 ccfolia-main-log.html로 저장됩니다. F12·콘솔이 필요 없습니다.

⬇ 룸 로그 수집 ← 이 버튼을 브라우저 북마크바로 드래그
  1. 위 버튼을 북마크바로 드래그하세요. (막히면 아래 콘솔 스크립트를 사용하세요.)
  2. 코코포리아 룸에서 ‘메인’ 탭을 열어 둡니다.
  3. 북마크의 ‘룸 로그 수집’을 클릭 → 위로 끝까지 훑어 전체 로그를 모아 파일로 저장합니다.
  4. 저장된 파일을 이 페이지로 끌어다 놓으면 곧바로 변환됩니다.
북마클릿이 막히면 · 콘솔 스크립트 사용

룸 ‘메인’ 탭에서 F12 → Console에 붙여넣고 실행하세요. 결과는 북마클릿과 동일합니다.
